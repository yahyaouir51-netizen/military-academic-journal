## كيفية الاستخدام

### 1️⃣ لكل عدد جديد:
```bash
# 1. عدّل ملف config.json في مجلد العدد
# 2. غيّر الصور والنصوص حسب الحاجة
# 3. احفظ الملف وشاهد النتيجة في المتصفح
```

### 2️⃣ فتح صفحة الغلاف:
```
1. افتح ملف cover-templates/index.html في المتصفح
2. استخدم لوحة المحرر السريع (أسفل يسار الشاشة)
3. غيّر رقم العدد والسنة واللون حسب رغبتك
4. اضغط "حمّل الصفحة كصورة" أو استخدم Ctrl+P لحفظ كـ PDF
```

### 3️⃣ تحرير الشعار:
- الملف `logo/logo.svg` قابل للتحرير الكامل
- يمكنك فتحه بأي محرر نصوص أو برنامج تصميم
- غيّر الألوان والنص والأشكال حسب الحاجة
